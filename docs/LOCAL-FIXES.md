# 2026-09-13 本機修正

目前固定資料夾的桌面 App 已套用以下修正：

- 標題保留實際換行高度，說明與按鈕依正常順序排列；視窗高度不足時允許捲動。
- 不透明度作用於整張卡片，包含 LOCKED IN 按鈕，避免按鈕仍完全不透明。滑桿拖曳時自動保存，不因收到狀態更新而重建滑桿。
- 尺寸與位置在變動後 150 毫秒自動保存，不依賴最後的 pointerup。結束工作階段前立即補存；失去指標捕捉或視窗焦點也會結束拖曳流程。
- 依使用者要求啟用登入 Windows 自動開啟。啟動項目指向固定資料夾中的桌面 App，並檢查是否被 Windows 停用。

此次更新保留既有執行檔、每週行程、位置、尺寸與其他偏好，只修改 App 資源中的四個檔案：main.cjs、widget.js、manager.js、styles.css。另保留更新前的資源及設定備份。

## 驗證

- 40 項單元測試通過。
- 另以本機版本的修正副本執行四項保存／啟動測試：沒有放開事件的拖曳仍存檔、冷啟動還原完整偏好、Windows 結束工作階段補存，以及啟動項目同步／停用處理。
- 無視窗瀏覽器檢查 10 種排版情境（空檔與長標題，5 種尺寸），確認文字與按鈕不重疊、按鈕及卡片有效不透明度相同，並確認滑桿自動保存且操作中不被替換。
- 安裝資源逐檔核對，僅預期的四個檔案改變，其餘 1755 個檔案內容一致。
- 本機 App 已重新啟動，主程序與 renderer 均存在。已讀回確認 Windows 啟動登錄項目、設定檔、尺寸及行程。
- 未操作使用者的滑鼠、鍵盤或桌面視窗，也沒有為測試重新開機。Windows 實際重新登入後的啟動仍待下次使用者登入確認。

這些是 v1.1.3 發布之後的本機與 main 分支修正，不代表既有 v1.1.3 下載附件已更新。
